# Prabod Sandaruwan — Portfolio

Minimal personal portfolio built with React and Vite to showcase projects, skills, and contact information.

Live demo: https:www.prabodsandaruwan.dev

## Features
- Clean, responsive layout
- Subtle animations via Framer Motion
- Typewriter effect (react-simple-typewriter)
- SEO-ready meta tags, Open Graph, Twitter Card, and JSON-LD
- Images lazy-loaded for performance

## Tech Stack
- React
- Vite
- Framer Motion
- react-simple-typewriter

## Local Setup
1. Install dependencies

```bash
npm install
```

2. Start development server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

4. Preview production build

```bash
npm run preview
```

## Project Structure (important files)
- `index.html` — base HTML, meta tags, OG, JSON-LD
- `src/App.jsx` — router and layout
- `src/pages/` — page components (Home, About, Work, Learning, Connect)
- `src/components/` — UI components (Nav, Project, ProjectTool, etc.)
- `src/assets/` — images and icons
- `src/styles/` or `src/pages/` CSS files — global and page styles
